VVideoLearnGiải pháp

Một cuốn sổ, bốn bước, người dùng luôn là tác giả.

1

Ghi bài mới

Thả PPTX / PDF / MD. Đọc cấu trúc, định vị bảng, sơ đồ, ảnh; OCR đúng vùng đó. Ngân sách quét 55 s.

2

Duyệt giáo án

Cây chương → trang → keyword có trọng số thời lượng. Thêm giờ trang này, hệ thống lấy từ trang khác, tổng không đổi.

3

Tạo lời giảng

Theo mẫu (0 token) hoặc AI viết. Luật từ nối, luật tiêu đề, SSML khoảng nghỉ, visual cue có mốc giờ.

4

Lời phê & xuất

10 kiểm định; lỗi hiện thành lời phê kèm cách sửa, nút sửa nhanh, sửa tay rồi kiểm lại. Xuất .txt, SSML, CLSG-IR.

VVideoLearnLợi thế cạnh tranh

Không đua bề nổi. Đào sâu ba ngách.

Thuật ngữ chuẩn

Từ điển thuật ngữ dùng chung cho keyword, lời giảng và kiểm định. Giữ nguyên CNN, kernel, feature map; chỉ Việt hoá từ tiếng Anh thừa trong câu tiếng Việt.

Đã sửa lỗi “feature map → feature mAP”.

Học tập cá nhân hoá

Nạp đề cương + kết quả quiz: thời lượng dồn vào phần có trong đề cương và phần người học làm sai; báo cả lỗ hổng mà slide chưa dạy.

Cho giảng viên và người tự ôn.

QA không “làm đẹp số”

Mọi điểm tính từ lời giảng cuối cùng; không điểm sàn, không trạng thái PASSED cứng. Mỗi lần chạy ghi log chỉ số và token thật.

DAR-P, grounding, từ nối, lặp tiêu đề…

OCR đúng chỗ

Khoanh vùng trước, chỉ OCR vùng đó: tesseract (tiền xử lý ảnh, dựng lại hàng/cột bảng) cho bảng & trang scan; Gemini vision cho sơ đồ, biểu đồ.

VVideoLearnChi phí & đo lường

Mỗi lần chạy biết chính xác tốn bao nhiêu token.

Đã có
Token lấy từ usage của API: prompt, output, thinking; lần nào API không trả usage thì đánh dấu “ước tính”.
Giá theo từng model; model chưa có giá thì ghi “chưa biết”, không đoán.
Cache kết quả LLM; cache hit được ghi 0 token.
Log benchmark mỗi lần chạy (Firestore + JSON): chỉ số, thời gian từng bước, từng lần gọi LLM.
Chế độ “Theo mẫu” 0 token; quét tài liệu gói keyword theo lô ≤ RPM free tier.

Mục tiêu vận hành

≈ $20 / 1,5 tháng cho giai đoạn thử nghiệm, nhờ template mặc định + cache + model rẻ cho tác vụ phụ.

Mục tiêu, chưa phải số đo.

Còn thiếu

  • Hạn mức token Normal / VIP
  • Redis cache phía server
  • Dashboard P99 latency

VVideoLearnHạ tầng & triển khai

MVP chạy được hôm nay. Production có lộ trình rõ.

MVP (đang chạy)

  • React 18 + Vite + Tailwind, deploy Vercel
  • Serverless /api: proxy Gemini, telemetry Langfuse
  • Firebase Auth + Firestore; Cloudinary lưu file nguồn
  • Pipeline chạy trên trình duyệt; OCR tesseract.js / Gemini
  • FastAPI (Python) có sẵn trong repo, chưa deploy

Production (kế hoạch)

  • Tách môi trường dev / staging / prod
  • Dockerfile cho backend, CI/CD GitHub Actions
  • Chuyển xử lý nặng (OCR, quét) sang worker server
  • Logging tập trung: request id, audit log, cảnh báo
  • CSDL cho user/usage (PostgreSQL) nếu vượt Firestore

  • Điểm đánh giá & phản hồi
